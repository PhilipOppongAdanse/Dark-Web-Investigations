# Dark-Web-Investigations
This investigation is about finding a vendor operating on a dark web marketplace, then using open-source intelligence (OSINT) to see if any publicly available information can be linked back to that vendor's online activity.

I followed a step-by-step approach looking around the dark web, building a profile of the vendor, tracing their usernames across other platforms, checking the infrastructure behind them, and finally trying to assess who they might really be.
